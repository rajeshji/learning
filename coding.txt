# 🎯 Your Daily Study Structure

Don't try to finish an entire tier in one day.

Use this cycle:

### Day N — Learn the pattern

```text
1. Why does this pattern exist?
2. Mental model
3. Recognition triggers
4. State
5. Transition
6. Variations
7. When NOT to use it
8. Combinations
```

### Then practice

```text
3 Easy
→ 3 Medium
→ 2 Hard
```

But don't solve them immediately one after another.

Use:

```text
Problem
 ↓
5–10 min recognition
 ↓
Identify pattern
 ↓
derive state
 ↓
attempt
 ↓
solution if stuck
 ↓
close solution
 ↓
re-code from memory
```
