05

CAP Theorem & PACELC Model

CAP Theorem

  • Consistency (C) — all nodes see the same data at the same time
  • Availability (A) — every request receives a response
  • Partition Tolerance (P) — system continues under network partition

PACELC Model

  • If Partition → choose between Availability or Consistency
  • Else → trade-off between Latency and Consistency
  • Cassandra → AP (eventual consistency)
  • MongoDB → CP (strong consistency with failover)
  • Spanner → CP (synchronous global consistency)
  • Dynamo → AP (leaderless, eventual consistency)
